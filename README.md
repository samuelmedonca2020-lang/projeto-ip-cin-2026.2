# Projeto IP — CIn-UFPE 2026.2

![Badge em Desenvolvimento](http://img.shields.io/static/v1?label=STATUS&message=WORK%20IN%20PROGRESS&color=GREEN&style=for-the-badge) 

Projeto final da disciplina de Introdução à Programação (2026.2) do Centro de Informática da UFPE. O jogo é uma experiência 2D *top-down* onde o jogador explora o bloco A do CIn, coleta itens temáticos ([portas lógicas](https://furtado.prof.ufu.br/site/teaching/SD/SD-Modulo4.pdf), operadores matemáticos e crachás) e deve conseguir sobreviver às versões malignas dos professores.

---

## Como executar
**Pré-requisitos:**
- [Python 3.10+](https://www.python.org/downloads/)
- Biblioteca *Pygame*

**Explicação passo a passo:**
1. Clona o repositório
```bash
git clone https://github.com/Jhon-Victor-Ramos/projeto-ip-cin-2026.2.git
```

2. Instala as dependências
```bash
pip install -r requirements.txt
```

3. Executa o jogo
```bash
python src/main.py
```
